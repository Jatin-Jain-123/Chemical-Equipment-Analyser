Chemical Equipment Analyser

Drop in a CSV of your pumps, valves, reactors and heat exchangers. Get average flowrate, pressure and temperature, a breakdown by equipment type, and a PDF report you can share. Use it in the browser or as a desktop app. Free and open source.

Try it with sample data View the code

What it does

One Django backend, two front ends: React in the browser and PyQt on the desktop.

CSV upload

Upload equipment data from the web or the desktop app. Files missing a required column are rejected with a clear message.

Instant analytics

Total equipment count, average flowrate, pressure and temperature, and how many of each equipment type, computed with Pandas.

Charts

Averages and type distribution charts: Chart.js on the web, Matplotlib on the desktop.

PDF reports

Download a one-page report for any dataset, generated with ReportLab.

Recent history

The last five uploads stay available, so you can compare today's readings with last week's.

Sign-in

Token-based authentication protects uploads, datasets and reports.

Run it yourself

You need Python with pip, and Node with npm.

  1. Clone the repository and install the backend: pip install -r requirements.txt
  2. Create a user: python manage.py createsuperuser
  3. Start the API: python manage.py migrate then python manage.py runserver
  4. Web app: cd web, npm install, npm run start
  5. Desktop app: cd desktop, python main.py
